# DataVis-DENGUE

Projeto de **Visualização de Dados** voltado à análise de dados epidemiológicos relacionados à dengue no Brasil.

O projeto utiliza dados públicos disponibilizados pelo Ministério da Saúde para explorar a distribuição e o comportamento dos casos de dengue por meio de técnicas de análise e visualização de dados.

## Sobre o projeto

O objetivo deste trabalho é utilizar recursos de visualização de dados para explorar informações relacionadas aos casos de dengue registrados no Brasil, buscando identificar padrões, distribuições e possíveis tendências presentes na base de dados.

A partir dos dados disponibilizados pelo Ministério da Saúde, são realizados processos de tratamento, análise e geração de visualizações que facilitam a interpretação das informações epidemiológicas.

## Fonte dos dados

Os dados utilizados neste projeto foram obtidos por meio do **Portal Brasileiro de Dados Abertos**, a partir do conjunto de dados de arboviroses e dengue disponibilizado pelo Ministério da Saúde.

**Fonte:** [Portal de Dados Abertos do Ministério da Saúde](https://dadosabertos.saude.gov.br/dataset/arboviroses-dengue)

Os dados são provenientes de sistemas de informação em saúde do Ministério da Saúde e podem estar sujeitos a atualizações, correções ou diferenças em relação a outras divulgações oficiais.

## Tecnologias utilizadas

O projeto foi desenvolvido em **Python**, utilizando bibliotecas voltadas para manipulação, análise e visualização de dados.

Principais tecnologias utilizadas:

* Python
* Matplotlib

## Visualizações

O projeto utiliza visualizações gráficas para facilitar a exploração dos dados de dengue.

Entre os aspectos que podem ser analisados estão:

* Variação nos sintomas entre sexos;
* Distribuição dos sintomas entre diferentes idades;
* Casos de agravamento em pessoas com diabetes;
* Frequência em casos graves em gestantes;

> As visualizações apresentadas neste repositório são resultado do processamento dos dados disponibilizados pela fonte oficial.
